# 第八阶段结论：平均收益明显，退化可靠性未过关

192段真实DI在12条真实NAM/IR链、0/+6dB两档上完成4608个渲染组合。先冻结[协议](stage8-protocol.md)、[配置](../experiments/stage8.json)、完整素材/折分及源码摘要，再运行五个留器材组。结果是内部开发验证；已有录音均曾被观察，不能当作全新确认。

**结论：低维共享协方差值得保留为研究候选，但没有通过全部预设门槛，不替换生产评分。** 自动EQ仍旁路，Free Bird仍暂停。

## 主结果

以下是未知输入trim、五器材组等权汇总。E0为无后EQ，E1为固定1200Hz/+3dB高架。遗憾值R表示“选中配置比相同候选库中最佳配置多出的同DI输出误差”，越小越好；不是听感百分比，也不是概率。

| 方法 | E0遗憾值 | E1遗憾值 | E1绝对SC误差 |
| --- | ---: | ---: | ---: |
| 同数据160频点中位评分 | 0.3977 | 0.2792 | 0.3932 |
| ERB低维类中心欧氏 | 0.4125 | 0.2572 | 0.3713 |
| ERB共享对角方差 | 0.3907 | 0.2150 | 0.3290 |
| ERB逐链LW收缩后平均 | 0.2150 | 0.1481 | 0.2621 |
| 同流程OAS敏感性对照 | 0.2195 | 0.1480 | 0.2621 |

LW的E1遗憾值相对160基线下降0.1311（46.96%），超过预定所需改善0.05584；5/5组改善。相对同低维/同中心的欧氏和对角方法，宏平均再下降0.1091和0.0669，所以收益不只是降维。但Aristides与LesPaul两组的E1中，对角法分别0.1180/0.1126，优于LW的0.1808/0.1839；不能说完整协方差对每类演奏都更好。

LW的E1链命中宏平均46.79%→69.79%，链与trim同时命中24.20%→37.65%。这是本轮同条件对照，不直接与历史不同任务的4/16相减比较。E1库内oracle的组等权SC约0.1140，选中LW仍为0.2621，平均改善不代表已足够接近目标。

## 为何仍不通过

LW相对160基线的E1逐任务退化P90，上限预先固定0.05：

| 琴/类型 | P90退化 |
| --- | ---: |
| Ibanez单音 | 0.1215 |
| Fender单音 | 0.1619 |
| Fender乐句 | 0.0000 |
| Aristides乐句 | 0.0333 |
| LesPaul乐句 | 0.1150 |
| Sire摘录 | 0.0000 |

三类超过上限。分组均值全部改善，并不能抵消这些明显恶化的案例。OAS成绩接近也不能事后替换已指定的LW主候选。

输入增益仍有问题：LW的E1数字trim命中宏平均约51.58%；已知真trim时，SC从0.2621降至0.2096、遗憾值从0.1481降至0.0955。但这个对照也会重新排列链，差值不是对“纯增益效应”的单独测量。已知增益仍有错链和退化，不能只靠修正增益解决。

已有结果的事后逐行审计：760个E1配对任务中，123个相对基线退化超过0.05，其中46个两法选同一链、仅增益不同，77个选不同链。已知增益的760个任务仍有82个退化；原123个案例中有71个在已知增益重排后仍退化。最严重四例的真目标均为G12-2204-3，涉及高音单音和两把琴的Lick1，完整选择及标签见完整发现。这些是相关任务行数，不是独立录音数，也未用于改选。

## 协方差是否可估

本批数据上，LW条件数134.76–270.36，无特征值触发数值下限；有效秩约7.45–8.37。20次预定分组重抽全部有效且平均收益为正，前三维子空间主角度的跨折/档中位数约9.70–25.69度。这支持矩阵数值可用、平均收益对本次训练组成有一定稳定性，不表示独立样本充分或真实部署可靠；20/20不是成功率置信区间。

主矩阵采用24个ERB频带的固定23维去电平坐标，不利用Q/H拟合。跨琴差异、主方向与音高/输入RMS的关联只是训练折内描述，接口、拾音器、乐手、录音增益仍混杂。Sire折还继承了历史Sire01推导的统一输入标定，不能称包括输入标定在内的完全外部留琴。

## 下一步优先级

先保留本次固定选择，定位退化中的增益偏好、特定链混淆、音域与素材类型差异；研究何时保留多个候选或拒答，以及增益约束和共享矩阵的适用范围。每项修改需另冻结，用未观察录音确认。暂不扩大增益格、搜更多收缩系数或直接启用EQ，也不因平均改善就开始Free Bird。

合成和弦/阻尼仍为未启用压力支线，真实力度、带标注真实和弦和闷音覆盖缺口不变。无需为了增加名义样本数先大量切片；后续优先有明确录音增益与父源关系的独立会话，并针对失败音域/链型设计对照。
