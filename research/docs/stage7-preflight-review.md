# 第七阶段首跑前检查

本文件仅登记首跑前的设计选择；正式执行还须另写 `locked-plan.json`。数据选择只使用来源、标签、音频头与原始字节，未按音频特征或试听成绩选录。

- 采用 18 个完整单声部拨弦乐句，保持同一乐句的三个吉他版本在同一角色。校准为乐句 1–3，新留出为 4–6。余音标签与下个音符尾部交叠不等同于同时拨和弦；这里评价单声部起音序列，不宣称声学信号始终只有一个基频。
- 完整普通单音乐句样本稀少。已知校准/新留出分别只有 16/5 个快速异音对、12/9 个同音重拨对，均无 200 ms 内的同音重拨。维持充分证据门槛，不用降低标准或同乐句跨组来凑数。允许研究性选参和描述性新留出比较，整体确认需报告证据不足。
- 原 XML 的 `4.2368→4.4368` 秒恰为 200 ms，二进制浮点相减可能略大于 0.2。标签汇总已修为十进制精确运算；方法评估统一到整数微秒闭区间，并加入这一真实边界的工程用例。原 WAV/XML 字节保持。
- 两种合并只在已有峰中保留原帧，不移位、不造峰；第一峰规则用最后一个保留峰作锚点，避免一串小间隔峰无限延长合并区间。最强峰规则按原包络强度排序，等强取早峰。
- 风险按合并前后独立匹配得到的真事件 ID 检查，不能把“删除了某个已配峰”直接等同于“漏了真实拨弦”，因为另一保留峰可能重新恢复该事件。空的快速同音组不能作为安全证据。
- 新留出后才回放第六阶段 156 个旧孤立音，先要求原始预测逐条重现。旧资料只用于观察已知重复峰是否减少，不参与新参数选择或确认。

128 ms / 0.8 音高候选、旧基线及第六阶段全部结果保留。本轮不开始 Free Bird、湿声检索或自动 EQ。
