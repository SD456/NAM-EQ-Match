# 第三阶段跨演奏检索与错误 EQ 实验协议

给定一段目标吉他湿声，用与参考乐句分开裁取的干吉他探针检索 NAM、箱体和数字输入增益。在一段新的留出 DI 上，检验选定的设置能否复现目标链的响应。四种评分和四种校正方案使用相同目标。本轮只做封闭候选库研究，生产评分参数沿用第二阶段版本，Free Bird 继续暂停。[第二阶段结论](stage2-conclusions.md)

## 素材、校准与盲区

| 角色 | 搜索前可用的信息 | 用途 |
| --- | --- | --- |
| P0、P1、P2 | 三段各 8 秒的干声 | 给每条候选链和每个增益建立探针库。P0 也是单探针对照。 |
| R0、R1 | 每例给检索器其中一段演奏的目标湿声 | 由评测端用真链、真输入增益和指定后置 EQ 生成。检索和拟合仅接收湿声。 |
| H0 | 在检索和滤波器确定后提供一段干声 | 分别送入真链与选中链，评价同一演奏上的响应。 |
| 第二阶段 A | 原始 RMS | 只提供公共校准系数。第二阶段 A/B/C 的检索或留出结果均不参加本轮计数。 |

新录音 02/03 的下载主机未能完成 DNS 解析。开始检索前启用同录音裁段的备用方案。Guitar-TECHS P3 的同一把 Sire T7、同一次 01 号录音，24–32、32–40、40–48 秒依次取 P0/P1/P2，48–56、56–64 秒取 R0/R1，64–72 秒取 H0。区间左闭右开，互不占用样本，也与旧 A/B/C 的 0–24 秒分开。**这里只有一个留出乐句**。这套划分可检验同一次录音内更换乐句的影响，跨录音、吉他或乐手的可靠性仍待实测。[DI 许可、来源、样本区间与哈希](../assets/stage3/di-provenance.json)

源立体声的两个声道相同，取左声道，保留 48 kHz 及原始电平。全程用旧 A 的 RMS 求一个比例 `10^(−18/20) / RMS(A)`，先将各段采样转为 float64，再乘共同系数与该档数字增益送入 NAM。各段共用比例，保留力度差异。源硬件输入增益未知，增益测量单位为此校准下的数字 dB。

复用原 12 条候选（10 个 NAM 和两条换箱体的附加链）。目标为 `AMP-2204-1` 和 `AMP-Sbgo-1` 各配原主箱体，以及完整链 `G12-2204-3` 和 `V30-SLO1-3`。分别用 0、+6 dB 真增益处理 R0、R1，目标后级为 E0 直通或 E1 固定 +3 dB、1200 Hz 高频搁架，Q = 1/√2。4 条链 × 2 档 × 2 个参考 × 2 个 EQ = **32 个目标案例，每种 EQ 16 例**。四种评分合计 128 个检索决定。多个案例共享录音、目标模型、箱体和留出乐句，计数仅描述这批固定材料。[模型与箱体来源](../assets/stage2/models-ir-provenance.json) · [第二阶段冻结配置](../experiments/stage2.json)

## 两种评分 × 两种探针用法

| 方法 | 对一个目标、一个候选及同一档增益的分数 |
| --- | --- |
| `current_single` | P0 的既有 `nonlinear_distance(candidate, target)["total"] + 0.25 × eq_penalty(candidate, target)`。 |
| `spectrum_single` | P0 的半倍频程平滑 LTAS 距离。 |
| `current_multi` | 分别在 P0、P1、P2 上算既有分数，取三个标量的中位数。 |
| `spectrum_multi` | 分别在 P0、P1、P2 上算相同的平滑 LTAS 距离，取三个标量的中位数。 |

平滑谱取 Welch 功率谱（8192 点 Hann 窗、50% overlap），在每倍频程 24 点的对数网格以半倍频程平滑 dB 谱。计算 80–8000 Hz 内目标与候选的谱差，减去这些频点差值的中位数后取平均绝对值，单位 dB。第二阶段的 `eq_only` 使用既有指纹的六分之一倍频程谱，又沿用其全频居中方式。两个实验的谱基线应分别报告。[频谱与冻结评分实现](../vendor/NAM-EQ-Match/tonematch/features.py)

每种方法均穷举 12 条候选 × −12 至 +12 dB 的 25 个整数档。在**同一增益**汇总多探针分数后，给每条候选选最低分增益，再按各链最低分排序。每个探针独自挑增益会让同一链具有三个部署设置，破坏对照。并列时用冻结的候选顺序与递增的增益顺序决定。仅比较完整链身份时，NAM 和箱体均须匹配。精确 Top1 和 Top3 分开列出 E0/E1 的命中数，另列错误集中在哪些教师链或参考。四种方法的单探针／多探针差在同一案例内配对，现有分数和平滑谱分数的绝对数值单位不同。

## 增益漂移与错误校正

每例记录每种评分下每条链的全部 25 档分数、胜者增益与前几名。固定真链重读这条曲线，统计最佳档与真实数字档的绝对差，在**全部**案例中衡量增益偏差。另列真实完整链恰为首选的子集及其分母。错链的名义增益无法直接换算为原链的驱动误差。相同设置下还可配对比较 R0→R1、E0→E1 的最佳档变化，区分演奏或目标着色引起的漂移。

对每条候选链，记这 25 档分数中最大值与最小值之差为 `span`。把 `score(g) ≤ min(score) + 0.05 × span` 的整数档标为近最优；当 `span < 1e−9` 时保留全部 25 档。按相邻 1 dB 档连接区间，多段分开保存。给出真链近优集合对真档的覆盖数、集合大小和宽度，区分“一个窄区间覆盖真档”与“所有档位都被保留”。该集合刻画固定探针和评分下的局部可分辨性，无统计置信水平。

对每个检索决定固定所选完整链和增益，比较直通、P0 单段拟合、三探针曲线逐频中位数、带一致性门槛的曲线。先用目标湿声减各候选探针的半倍频程平滑谱，按 200–4000 Hz 频点的中位数移除整体电平差。沿用既有频带两端渐消、2048 taps 最小相位和 ±4.5 dB 上下限。对非直通方案检查实际量化、截短后的 FIR 频响，包括 FFT 栅格间的裕量。存录实际响应范围。相同的真链、真增益另作诊断，对 E0 此时理想校正为直通；可直接量出跨演奏谱拟合凭空引入的误差。[受限 EQ 实现](../vendor/NAM-EQ-Match/tonematch/match_eq.py)

无门槛的三探针拟合使用三条曲线在每个频点的中位数。保守拟合先逐频检查三条曲线是否**全部同向**、最大值与最小值的差是否 ≤3 dB，以及中位数绝对值是否 ≥1 dB。三个条件同时满足时保留中位数，其他频点置零。两种三探针方案均再做一次相同的半倍频程高斯平滑，故两者之间只比较门控的贡献。门槛控制平滑前保留的频点，邻频仍会影响最终 FIR 曲线。P0 单段拟合沿用第二阶段原算法，因此与三段中位数的差异同时包含探针数和一次额外平滑。

三段探针都与**同一段**目标湿声作差。若目标演奏中某些音高出现得特别多，三条曲线可以一起朝错误方向修正。逐例计算 H0 校正后减直通时的 ΔSC 和 ΔLTAS。任一项超过 +0.02 SC 或 +0.25 dB 即计实质恶化；对称地，任一项低于 −0.02 或 −0.25 dB 即计实质改善。两项方向相反且同时越界的案例应能在逐例值中识别。E0 与 E1 均列改善、恶化及已经过筛却因校正失守的例数，均注明分母。这些界线只用于筛选本次实验的变化。

## 配对验证与复核

H0 上的目标为真链、真增益和该例 E0/E1 的输出。候选为已冻结的链、增益及四种校正之一。完整保留卷积尾部，短侧补零后仅在指标内部按整段 RMS 对齐。MRSTFT 谱收敛度（SC）沿用 512、2048、8192 点窗及 75% overlap 的三个幅度谱差范数比的均值。LTAS 误差为 80–8000 Hz 的居中谱差 MAE。单例同时满足 SC ≤ 0.20 且 LTAS ≤ 1.5 dB 时过筛。保留逐例数值、相对同一 H0 直通时的增量及分母。拟合与选优不得读取这些指标。[配对评价函数](../scripts/stage2_benchmark.py)

在 E0 和 E1 各自 16 例中，检索内部门槛均为 Exact Top1 ≥12/16、Exact Top3 ≥14/16。只有两组均达到门槛，且各组强制真链增益绝对误差中位数分别比同类分数的单探针至少少 1 dB、选中链直通时 H0 过筛数均未减少，才称多探针取得联合改进。其余情况逐项解释，包括只改善链身份或只改善 EQ 的情形。

复算时先核对 P、R、H 的身份、来源区间及哈希，确认候选特征缓存的键只含 P、候选和档位。检索器和 EQ 拟合器只能接收目标湿声与预定的候选探针，真值只用于制造湿声及单列的评价或真链诊断。与同真值、同 H 的 E0 直通自对照应取得数值零附近的两项误差。多个方法偶然选中同一链、同一增益时，其同一 H、同一校正模式的评估也应一致。缓存中断续跑须核对配置、素材与参与运算的代码身份。研究门槛仅用于本小型封闭库筛选，不能推断听感等价、跨吉他/设备准确率或生产可用性。[冻结机器配置](../experiments/stage3.json)
