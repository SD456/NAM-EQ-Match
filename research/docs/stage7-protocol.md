# 第七阶段 · 连续电吉他 DI 的相邻起音峰合并

第六阶段的 64 ms 检测器在每组 78 个孤立拨弦上均全部命中，同时在校准、留出各多报 52、66 次。其中 42、58 次落在已标注拨弦的 ±50 ms 内。第七阶段检验同一检测器在连续演奏中能否减少这种多报，以及合并是否会吞掉快速换音或同音重拨。前一轮 128 ms / 0.8 音高候选、两轮失败记录及生产基线继续作为历史参照。[第六阶段结果](stage6-findings.md)

## 数据和顺序

- 准入材料为实际电吉他直接输入的连续单音演奏。同一时基上应有完整的音符起音和 MIDI 标签，并能按原始标注或采录说明识别普通逐音拨弦。标签用于准入、分组与评分。原始 WAV、配对标注和来源/许可说明留存，记录源录音/演奏标识、边界、标签数及 SHA-256。记录缺失或不明的采录信息。
- 使用 IDMT-SMT-Guitar 原归档 `dataset2` 的 Aristides 010、Fender Stratocaster、Gibson Les Paul 三把吉他，每把各取六个普通拨奏 `Lick*_KN` 的完整录音及同名 XML。Lick 1、2、3 共九条作校准，Lick 4、5、6 共九条作新留出。每组包含三个不同乐句；同一乐句的三种吉他演奏是组内重复。全部 XML 登记乐手 Christian Kehling，拾音器档位未知。此设计评估新乐句，无法估计跨乐手或跨乐器泛化。[IDMT 发布记录](https://zenodo.org/records/7544110)
- 同一乐句的不同吉他、奏法或拾音器版本，以及同一演奏的片段和声道须在同一组；重复音频哈希不得跨组。已观察的第六阶段 Fender 及 Ibanez 孤立音录音均不具有新留出资格。准入时核对完整文件清单、录音角色与上游采录说明。
- 支持门槛逐组检查三条新录音和三类音对：快速换音 `fast_change`、同音重拨 `repeat`、快速同音重拨 `fast_repeat`（重拨中 IOI ≤200 ms 的子组）各至少 20 对。子组与母组可包含同一音对。报告各类有样本的独立录音乐句数。先用标签审查类别支持、间隔与录音数，再冻结角色。单音乐句中自然余音或标注的尾部交叠可以保留，并须披露；和弦、同时起音、无完整起音标签或拨奏方式不明的条目记录原因。不足时仍可报告描述性成绩，确认结论记作 `insufficient_evidence`。
- 数据准入只读元数据、标签、音频头和原始字节摘要。在校准前另行写出冻结锁，绑定本协议、有效参数、实现、运行库版本、组别、输入与历史保护文件摘要。先跑校准并写出绑定校准与锁哈希的唯一候选或无候选判决，再对新留出执行一次评价。查看留出结果后不得调整配对、网格或升级另一候选。真实峰值、试听或特征均不得用于选录或划分。

冻结前的 XML 盘点如下。按十进制原标注计算 IOI，恰为边界的对计入右端闭区间。例如 `AR_Lick3_KN` 的 4.2368 → 4.4368 秒恰为 200 ms，应计入快速换音。两组都没有 ≤200 ms 的同音重拨，也没有 ≤80 ms 的任何真实音对。

## 候选检测器

全录音走原第六阶段起音分支。峰值归一化并多相重采样到 16 kHz；hop 为 256 点（16 ms）。在完整录音上取 `librosa.onset.onset_strength` 的包络，使用 `onset_detect(backtrack=False, units="frames")` 的既有检峰参数，保留所有原始峰。零点不自动报峰，全静音输出零个预测。输入不包含起音标签、MIDI、音高预测或演奏类别。原始 1024 点 FFT（64 ms，记为 raw64）为唯一合并输入，原始 2048 点 FFT（128 ms）单独作诊断参照。

| 规则 | 输入、保留值和确定性 |
| --- | --- |
| `first` | 按原峰帧号由小到大访问，保留第一个峰。后续峰若距上一个保留峰 ≤ 半径则归入该保留峰，否则保留。被抑制的峰不延长区间。 |
| `strongest` | 按各原峰帧上的原始包络值从大到小访问，等强时先取较早帧。访问一个保留峰时抑制半径内所有尚未处理的峰，并登记归属；被抑制的峰不参与后续竞争。最后按时间顺序输出。 |

两种方法各取整数半径 2、3、4、5 帧（32、48、64、80 ms，包括边界），共八项。每个预测都沿用保留峰的原帧号；输出可逐峰重建哪些峰保留、哪些被哪个峰抑制。两个原始窗各自保留为对照。只改变检测后处理，不移位、平均或新增峰。

## 事件匹配与风险计数

主容差为 ±50 ms，±100 ms 供描述。先核对原始 XML 时间戳可精确表示为整数微秒；将秒数四舍五入为整数微秒，峰帧号乘以 16000 得微秒。匹配、近邻 FP、IOI 与分档均在整数微秒上比较，含容差端点。逐录音沿用第六阶段的一对一有序最大数量匹配，按时间从早到晚取首个在容差内的预测。每个方法都用其完整预测独立执行一次匹配，保存配对的真事件 ID、预测帧号及有符号误差。每次匹配一对计 TP，多余预测计 FP，未命中的真事件计 FN。每组报告整数分母、汇总 P/R/F1、逐录音 F1 及其等录音均值（macro F1）、偏移中位数及绝对偏移中位数。没有匹配时偏移留空。所有选择和判决只用 ±50 ms 主成绩。

对每个未匹配预测，若距任一已匹配真实起音 ≤50 ms，计作一次近邻多报；其余计作其他多报。多个标签同时接近一个预测时仍只计一次。近邻位置只说明可能的重复峰；邻近漏标、原标注时差也可产生相同观测。

逐录音在原始连续标签中取时间相邻的两个普通拨弦事件，保留两端 ID、MIDI 与间隔（IOI）。`fast_change` 为后音与前音 MIDI 不同且 IOI ≤200 ms；`repeat` 为相同 MIDI 的相邻重拨，并单报其中 IOI ≤200 ms 的子组。各类分别列出有样本的录音数、对数、最短 IOI，区分 ≤80 ms、(80,180] ms、(180,200] ms、>200 ms 四档。180 ms 为最大合并半径加两端各 50 ms 的评分容差。每一对各自计数，连续三音可形成两对；估计不确定性时不能把共享音符的对当成独立演奏。

每类报告后音召回（命中的后音数/该类对数）与双端命中率（两端都命中的对数/该类对数），并列出 raw64 命中后被候选丢失的后音 ID 和从双端命中变成不完整的音对 ID。即使候选在其他位置重新命中，丢失的 ID 也计入。对每个丢失的基线真事件，查明其原配峰被抑制，还是原配峰仍在、重匹配时改配了别的事件。前者报告原帧、抑制它的邻峰和距离，并可核对该邻峰是否匹配另一个真拨弦。损失定义依据上述匹配，无法给每个被抑制峰赋予确定的物理归因。原检测器本来漏掉的事件单独计数。IOI ≤100 ms 时真值容差窗可能重叠。±50 ms 为评分容差，单条原标签的物理误差未知。

## 选择与判决

在校准集上，候选须相对 raw64 同时降低近邻多报数、提高 macro F1，且在 `fast_change`、`repeat`（含其中的 `fast_repeat`）均未丢失 raw64 已命中的后音或已双端命中的音对。合格者按未舍入的 macro F1 降序、总 FP 升序、半径升序、`first` 优先于 `strongest` 排列。所有合并项均不合格时锁定无候选，保留基线。任一角色的音对数不足 20 仍可完成这个研究性选择和留出误合并检查。分母为零的格记为空；没有原先双端命中的音对时，该类的损失率不可估计。

校准选择持久化并校验后，在新留出一次性计算 raw64、原始 128 ms 对照及八种冻结合并项。全部设置列入描述性表；确认判决只读取校准锁定项、raw64 与两组样本支持。两组均达到最低支持、候选在留出再次通过增益与逐 ID 保全检查且留出 macro F1 ≥0.80，才通过本轮起音门槛。任一组未满足最低支持时，整体记作 `insufficient_evidence`；并列公开每项数值、任何可观察的退化以及锁定无候选的情况。后续补录采用新演奏、新冻结锁与独立确认组。[补录规格](stage7-recording-spec.md)

最后在原第六阶段 156 个孤立音上回放。逐录音确认 raw64 和原始 128 ms 全部预测峰与第六阶段 `predicted_onsets` 相同；若出现差异，报告具体文件和帧并停止解释本项。分别保留原 Ibanez、Fender 角色，列出八个冻结合并项及校准锁定项的 TP/FP/FN、近邻多报和 F1，与该组原始多报 52、66 对照。若整数微秒的闭边界匹配与第六阶段浮点评分在临界值有差异，单独列出相应条目并保留原评分。历史回放只解释已知失败是否改善，不参与校准选择、新留出或选后晋升。

本轮只评估所测干声单音起音。Free Bird、自动 EQ、湿声检索、生产评分及部署维持原状态。
