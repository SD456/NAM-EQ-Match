# 第六阶段实验协议 · 用真实电吉他 DI 标签校准音高与起音

第五阶段 3 条干声探针和 32 条湿声查询均有原始 pYIN 有声标志，却没有帧通过 0.8 概率门槛。那些录音缺少独立音高真值。本轮检验加长音高分析窗后，覆盖与音高正确率怎样变化，以及保留较短的起音分析窗能否更准确地定位一次拨弦。[第五阶段诊断](stage5-findings.md)

## 素材及冻结顺序

1. 采用 IDMT-SMT-Guitar Dataset 1 的电吉他直录单音 WAV 和对应的事件 XML。官方记录说明整个数据库含一种麦克风采集情形，因此逐文件按官方乐器、采集路径和目录映射核对。只采用下面两个单音目录，每个目录计划检查全部 78 对文件。记录取样来源、许可、乐器、拾音器、文件标识、原始音频和标签哈希。[IDMT 官方记录](https://zenodo.org/records/7544110)
2. 校准固定用 Ibanez PowerStrat 的琴颈双线圈，留出固定用 Fender Strat 的琴颈单线圈。两组虽可弹奏相同音高，音频来自不同乐器的独立录音。划分单位是整条录音与乐器；本设计只能检验这一组乐器/拾音器变化。其他拾音器轨道不当作新的独立乐器。同一演奏的切片、重复文件或衍生声道不得跨组。核对文件哈希及上游录音标识。
3. 从 XML 读取每条录音唯一有效音符的 MIDI 与起止秒数，核对原时基、声道和 WAV 时长。只纳入无重叠、音高恒定、普通单音拨奏且完整标注的录音。排除和弦、复音、特殊变音技巧、超出分析音域或时基不明的条目；逐条登记排除原因。事件标签供数据准入和评分，估计器只读取整条 DI。每组至少须有 12 个带稳定帧的有效音符和 3 个不同的稳定段 MIDI 音高，否则登记准入失败。采集元数据检查发现三条校准标签的结束时间比 WAV 长度多不到 33 微秒；允许不超过 50 微秒的十进制舍入差，并仅在解析事件中取 min(标签结束, 文件时长)，同时保留原值；原件不改。
4. 用标签、音频文件头和字节摘要完成数据核对。在计算任何真实音频特征之前，固化协议、参数、代码、依赖版本、源音频与配对标签、解析后事件、分组与旧基线的锁及哈希。合成样本只供自检。先在校准组运行全部候选，将选择或无可用设置的决定落盘并绑定锁文件，再打开留出组。保存完整结果、各录音分母和拒答。留出诊断只作描述，不能再据之改选。

## 音频前端

在完整单声道 DI 上作峰值归一化、多相滤波重采样至 16 kHz。各路共用从录音零点起每 256 个采样一点的时间轴，帧中心间距 16 ms。显式居中补零。禁止根据标签裁片、位移、选择最响事件或消除偏差。输入格式与锁不符时报错，静音录音按未检出计。

| 项目 | 冻结值与用途 |
| --- | --- |
| 音高窗 | 1024 与 2048 样本（64、128 ms）。分别跑 pYIN，`fmin=82.4`、`fmax=1319` Hz、`resolution=0.5` 半音、hop 256，`center=True, pad_mode='constant'` 居中补零。 |
| 概率门槛 | 每窗用 `[0, 0.1, 0.2, 0.4, 0.6, 0.8]`，共 12 项。等于门槛时通过。0 仍要求原始有声标志与有限 F0。1024/0.8 作为沿用第五阶段 pYIN 参数的参照，使用本轮整条录音和统一边缘。 |
| 共用有声筛选 | 1024 样本 RMS 严格大于整条录音 RMS 第 95 百分位的 0.01 倍；帧中心 `0.064 ≤ t < 录音时长 − 0.064` 秒。录音边缘统一按最长窗裁定。 |
| 起音 | 主检测固定短 FFT 1024，诊断对照仅将 FFT 改为 2048。均使用相同 hop 256、同一 `librosa.onset.onset_strength` 与 `onset_detect(backtrack=False)` 检峰配置。各自对整条录音输出全部起音；两路均独立于任何音高或标签门槛。 |

校准表在同一门槛下成对比较窗长，在同一窗长下比较门槛。给出原始有声标志数、保留量、真实标签音高错误和八度错。这里的概率是估计器输出，其数值是否对应实际正确率由标注成绩检验。

## 音高与拒答

参考为 A4=440 Hz、MIDI 40–88（含两端）内的标称谱面音高。对于标签区间 `[on, off)`，两窗统一取 `[on + 0.114, off − 0.114)` 的帧中心作为主要评分范围。114 ms 包括最长窗的一半 64 ms 及实验预留的 50 ms 标签边界保护量。无稳定中心的短音单列，起音评分仍包括这些事件。156 条 XML 中有 151 条的结束时间为 2.5 秒，98 条的起音为 0.2 秒。称为“稳定段”的是去除边界后的标签区间，指向名义音高；这些时间并未逐帧证明尾音衰减后仍有可辨基频。

- 保留 pYIN 未取整的 Hz，计算音分差 `e = 1200 × log2(f0 / (440 × 2^((midi−69)/12)))`。音高正确取 `|e| ≤ 50`，单八度错取 `||e|−1200| ≤ 50`。
- 每个有稳定帧的音符权重为 1，其各帧权重等于稳定帧数的倒数。设音符数为 N，A、C、O 分别为获答、正确及单八度错误帧的权重和。报告覆盖 A/N、已答正确 C/A、全分母正确 C/N、已答八度错 O/A，另列原始帧数、音符数及零获答音符数。A=0 时条件比率为空，全分母正确为 0。
- 按标称 MIDI 40–51、52–63、64–75、76–88 分段给出支持数与成绩。另按标称起音后的 [0,80) ms 和 [120,400) ms 描述起音段、持续段，均截于标注结束。阶段诊断使用各段内帧中心，单独报告各自覆盖及正确情况，不并入稳定段选参。起音邻近帧会混合拨弦前后能量且受标签时间误差影响。零支持的格留空。
- 校准项须同时满足覆盖 ≥0.60 与已答正确率 ≥0.90。合格项依次按全分母正确率较高、已答八度错率较低、音高窗较短、概率门槛较高排序，比较未四舍五入的数值。若全部未过，固化“无可用设置”；仅报告参照和诊断，保留拒答。

## 起音与判决

两种起音窗均在原录音时间坐标上，以 ±50 ms 为主容差，±100 ms 为敏感性诊断。每个 XML 事件与检测事件一对一配对：在时间顺序上取最早落入容差的未匹配预测；窗口外和其余多余预测全部计误报。录音的唯一真实起音没有匹配时计漏报。预测器保留整条录音的全部检峰，不能借标签只留下最接近的一次。时间零不自动算一次拨弦。此单事件语料无法评价连续重复拨同一音或快速换音。

对各容差及两种窗给出 TP、FP、FN、精确率、召回率、F1、有符号时间偏移中位数（预测减标签）和绝对偏移中位数。F1 取 `2TP/(2TP+FP+FN)`。有真实事件却无预测时 F1 为 0，匹配数为零时两类偏移均为空。独立研究对 50 个 IDMT 音符重新标注，其与原标签的绝对时间差均值为 8.5 ms、标准差 9.2 ms。本轮衡量检测相对原标签的偏差，±50 ms 是评估容差，单条标签的物理真值精度仍未知。[Stefani 等，表 2](https://domenicostefani.com/publications/2024AM-preciseonset.pdf)

进入下一轮湿声验证须同时满足以下三项，仅据先行锁定的音高设置与主起音窗判决。

1. 留出稳定段的等音符加权覆盖 ≥0.60。
2. 留出稳定段的已答音高正确率 ≥0.90。
3. 留出组主起音窗 1024 在 ±50 ms 容差的 F1 ≥0.80。

任何一项失败都报告对应分母和具体差距。即使 2048 起音对照或其他概率格表现更好，也不替换主项。结果只支持所测干声、乐器和有样本的音域。湿声音准、失真下的八度错误、真实力度与 trim、选链和部署均须另外验证；第五阶段失败记录、新 EQ 旁路、Free Bird 暂停状态继续保留。
