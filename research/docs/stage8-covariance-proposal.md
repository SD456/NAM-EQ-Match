# 第八阶段草案：低维、共享类内协方差的音色检索

日期：2026-11-16。**状态为待冻结的方案草案，不是已执行协议。** 本次只做来源与方案审查，没有批量渲染、估计协方差、生成和弦/闷音近似或更改评分。保留阶段1–7、128 ms 音高候选和已有试听；Free Bird、自动 EQ 与部署验证仍不启动。

## 目标与类定义

采用用户提出的定义：链身份 `c = NAM + 基础箱体 IR（若模型已含箱体则不重复）`。输入 trim `g` 是单独条件，不将多个档位当作独立演奏。类内刺激为不同的真实 DI `x_i`，特征为 `z(c,g,i)=φ(F(c,g,x_i))`。每条链可拥有192个输入样本，但其来源强相关，不宣称有效样本数等于192、乘以12条链或乘以增益数，也不未经估计就写成“有效几十个”。

研究优先级转到“完整 DI 池的受控检索验证”，音高/起音原型保留为辅助分支。本轮谱特征不依赖起音检峰，避免先把起音研究做到达标才能验证整体音色。

首轮验证完整 DI 库上的评分，并在相同 DI、特征和类中心下检查共享协方差是否额外改善新 DI 输出。不用不同任务下的旧三探针结果单独归因“扩充 DI 数量”的收益；若要拆开这个因素，须另加同折、同特征、冻结抽样规则的少量 DI 对照。主目标为前向音色质量，真链身份命中只作诊断。

## 有限范围试验

以下为本次技术建议默认值，正式冻结须与实现、清单逐项一致。

- 输入池为 [覆盖清单](di-coverage.md) 的192段；源原件不改，44.1 kHz 素材在渲染前用保幅多相滤波转48 kHz。继承一次公共输入校准，不逐段按 RMS 重归一化；报告原始电平，未知硬件增益仍是混杂因素。
- 候选沿用12条已登记链。首轮只用0、+6 dB两个输入条件，共 `192×12×2=4608` 个独特完整链输入组合，缓存特征及少量试听，不保存成千上万份冗余湿声。若 H 质量评价另行流式复渲染，实际调用数会增加，不能把4608写成保证的总调用数。它是受限域筛选，不冒充原25档检索。
- 第一套低维表示固定为80–8000 Hz的24个 ERB 分带对数能量。令频带向量为 `b`，用预先固定、与全1向量正交的同一套 `24×23` 正交基 `B`（例如 Helmert contrasts），取 `z=Bᵀb`，消去常量电平；所有折与增益共用这套23维坐标。保留原始频谱诊断，首轮不同时加入新动态特征。PCA/倒谱或12维降维属于后续有条件消融，不能看外层留琴结果后重选并仍称同次确认。
- 输出只作特征电平处理；NAM 前输入电平保持。箱体完整卷积尾部保留，整录音取特征，不按真起音剪出容易片段。每文件一个特征向量，时长/内容与来源均登记。
- 未知增益检索只在同一两档上比较全部方法，并另列已知增益诊断以分开增益混淆。原25档的旧结果只在精确历史任务回放中使用。

24频带、23个非冗余坐标是控制复杂度的工作默认，不是经验有效秩已测得。若直接将24频带减均值后在24维做收缩，完全无信号的常量轴也会获得人造方差，跨档 logdet 会计入它；因此须先去掉这条轴。样本维数比5–10倍是经验提醒，不保证相关数据上的稳定性。

## 对照与共享矩阵

所有新方法在同一外层训练 DI、查询、候选和增益格上运行：

| 方法 | 作用 |
| --- | --- |
| 原160频点平滑谱、多 DI 中位距离 | 使用相同允许训练 DI 重建组匹配基线，为低维/协方差提供同数据对照 |
| 24 ERB投影到23维、类中心欧氏距离 | 控制低维表示与类中心聚合的合并变化 |
| 同23维与类中心、共享对角方差 | 检查在这套固定坐标中是否只需逐维尺度调整 |
| 同23维与类中心、按增益共享 Ledoit–Wolf 协方差 | 预先指定的协方差主候选 |
| 同流程 OAS | 预设敏感性对照，不在外层成绩上择优替换主项 |

上述对照不能单独分离“160→24维”和“中位距离→类中心”的贡献；协方差主比较则保证特征、类中心和训练 DI 一致。旧三探针基线单列历史回放，不能在留出 Sire 时仍拿 Sire 探针参与新训练。

训练折内按 `(c,g)` 求中心 `μ(c,g)` 和残差。未收缩的共享目标为各链类内协方差的等权平均，避免把类中心差异混入 Σ_w。同一 DI 经过不同链的残差是相关块，不能把 `12×N` 行直接解释成 `12×N` 个独立演奏。

草案主估计器：先在每条链同一组训练 DI 上估 Ledoit–Wolf 收缩矩阵，再跨链等权平均，得到所有链共用的 `Σ_w(g)`；OAS 对照同样处理。它准确称为“逐链收缩后等权平均”，不等价于对合并矩阵执行一次 LW。这样不靠拼接链数虚增解析估计的样本行数。它仍使用近似的采样假设，必须在组重抽与外层预测中检验，不能声称收缩系数在相关 DI 上已最优。首轮逐 DI 等权；按器材组重抽时保留组内文件与全部链/档渲染，报告孤立音的占比和敏感性。

默认 LW/OAS 的目标是 `tr(S)/p · I`，不是保留每维不同方差的任意对角阵。对角目标估计器应另行命名，不混称 LW/OAS。[LedoitWolf 文档](https://scikit-learn.org/stable/modules/generated/sklearn.covariance.LedoitWolf.html) · [OAS 文档](https://scikit-learn.org/stable/modules/generated/sklearn.covariance.OAS.html)

不同增益协方差在同一23维坐标内估计，跨档评分拟用等先验高斯近似；共享对角方差对照也在同一坐标中估计，并带对应 logdet，欧氏对照等价于跨档固定单位协方差：

`score(c,g;r) = (z_r−μ(c,g))ᵀ Σ_w(g)⁻¹ (z_r−μ(c,g)) + log det Σ_w(g)`。

它是评分假设，不是已校准的真实概率。只用马氏二次型再自由放大某档的协方差会偏爱更宽分布；不能通过任意 gain-scalar 把这个问题藏掉。若结构随增益变化，单一标量也不能修复各方向的变化。实现前须验证数值正定性与跨档可比性。

## 吉他、录音与训练边界

按覆盖表的五个保守器材组做外层留组：Ibanez、Fender型号族、Aristides、Les Paul、Sire。两批 Fender 是否同实物未知，保守合组。每折所有变换、类中心和协方差只看训练组，查询 Q 与同 DI 裁判 H 不进入拟合；同一源文件切片只在同一角色。任何合成后代随全部父源联动，不能跨角色混配父音符。

主检验定义为留器材组，允许训练其他琴的同键位/同谱面，但仅支持这个条件。另做未见谱面检查时，整首同谱面各琴版本一起排除，单列训练量和结果，不能混用两种划分宣称双重泛化。五组的内容差异很大，逐折、逐数据类型报告，不用帧数或渲染数构造很窄的群体区间。

Q/H 必须在渲染前写出完整文件清单与父源关系。单音库不能把同一源的不同切片当独立 H；同音高跨弦也要记录关联。小组不足以支持独立 Q/H 时标缺项，不借回 H 拟合矩阵。Sire 外层可沿原04作 Q、05作 H，全部 Sire 源仍从训练排除。

跨琴差异先作描述性分析：孤立音的两琴78个弦品键位相配，乐句的三琴六首谱面相配。只在训练组内计算相同 `(c,g,内容)` 的跨琴特征差；相应家族少于两琴则不估其方差。拾音器、接口、session、乐手和输入电平混杂，这不是纯吉他随机效应，首轮不额外拟合并强行剔除一套“纯琴矩阵”。

所有现有录音已被观察，外层留组只能称内部开发验证。正式确认另取未观察录音。先执行内部筛选以决定是否值得补数据，避免把当前资料冒充新确认。

## 稳定性及防止消掉音色

保存样本与收缩后的特征值谱、有效秩描述、条件数、收缩量。按录音/吉他组联动重抽，重新拟合全部训练变换、中心与矩阵，再检查留组排名和质量遗憾值。接近的特征值允许主向量旋转，应比较领先子空间而非单向量符号；各折维数固定，若稳定性不足须另开低维方案，不能回看外层后在原报告里调维。

在有标签处检查方向与音高、弦位、琴组、输入 RMS/峰均比的关系；没有真实力度标签，不把方向命名为物理力度。还要检查类间中心距离/可分性及留出音色质量：演奏方向与音色方向可能重叠，白化不能不加检验地删除最大方差方向。

## 合成压力测试

真实主评估与合成压力分开。合成尚未生成，不能计入真实覆盖或独立样本数。

- 和弦近似：在同琴/拾音器来源下选择不同弦的2–4个普通单音，按原标签对齐起音，先合成 DI 再进入同一个非线性 NAM。不能先失真各音再相加。弦间共振、共同拨弦手势、物理拾音及采集差异未建模；数字输入峰值/RMS须记录。
- 合成和弦的加权规则、公共衰减与弦品组合需先固定，不逐条按目标响度调输入。增加音符数也改变输入能量，结果同时受复音和驱动变化影响，不能只归因互调。全程 FLOAT，不以隐藏限幅处理过载。
- 闷音近似：冻结低通与衰减包络配方，仅称阻尼/滤波压力，不称真实 palm mute；不据它宣称已覆盖闷音。
- 幅度缩放仍是数字电平或输入 trim；不生成真实力度标签。
- 合成物只用于独立描述性压力表，不参与首轮真实主矩阵的选择；若以后加入训练需新冻结，所有父素材跨折隔离。

## 主评价、旧门槛与止损

给定参考湿声 Q，选择器只看 Q 与训练候选库，得到 `(ĉ,ĝ)`。目标链拟沿用原4条已知目标、两档输入条件；E0 为直通，E1 继承阶段4固定高架（1200 Hz、+3 dB、Q=0.7071067811865476）。每个任务的 Q 与 H 目标使用同一后 EQ；检索候选保持无附加 EQ，不把未知校正混进本轮协方差收益。目标清单及聚合权重正式冻结时逐项列出。

在独立的同一套 H 干声上，分别运行所选参数与已知目标。主质量距离拟继承输出电平对齐的 MRSTFT spectral convergence；居中 LTAS、听评与绝对质量另报，不把不同单位临时加权成一个后验分数。仅存 ERB/160点谱不足以还原 MRSTFT：H 可逐源复渲染24个候选，流式计算全部目标/档/EQ的质量距离，再只缓存数值表；表与 H 湿声对选择器隔离，选中配置锁定后才读取。

对一组 H 先以冻结规则汇总同一 `(c,g)` 的质量距离，得到 `D_H(c,g)`，再计算：

`R = D_H(ĉ,ĝ) − min_(c,g∈相同候选格) D_H(c,g)`。

多个 H 共用一组选中参数和一组 oracle 参数，不对每个音符挑不同最优链。oracle、目标链/档及 H 只作事后裁判，不能回流检索。同时报告 `D_H(ĉ,ĝ)` 本身：遗憾值很低也可能只是整个库都不够像。

与同条件基线配对，分别报告 E0、E1，每个器材/父录音组的遗憾变化、绝对误差及退化尾部，再报组等权汇总。主检验不因单个容易组的样本多而占主导；Top1 为辅助诊断。

旧 E1 的4/16只来自原四目标×两档×同一04录音T0/T1。用户提出的≥9/16可保留为精确历史回放的工程里程碑；只有恢复相同候选、25档、探针/参考信息边界时才直接比较。新留琴、两档试验必须重跑同条件基线，不能把新表9/16直接对旧表4/16。

止损顺序：

1. 检查共享矩阵在分组重抽中能否保持可用、是否损害类间分离。
2. 在逐留琴折上看 E1 同 DI 遗憾值是否相对配对基线改善，且 E0 和退化尾部没有明显代价。绝对改善幅度、容许退化与 Q/H 名单须在正式冻结时定量写出，不能由这次尚未执行的草案声称已通过。
3. 若稳定改善，再恢复完整增益格并补真实和弦/闷音/新确认数据；先保留研究候选，不立即替换生产。
4. 若无改善，停止在该协方差分支继续堆参数。先区分特征、共享假设、样本支持、库覆盖与前处理问题，再转向用户提出的学习式比较器，用同 DI 渲染距离作监督目标。阴性结果只能说此分支未证明有效，不能证明现有特征必然无用。
