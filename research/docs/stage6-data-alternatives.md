# Stage 6: public DI data alternatives

The selected source is [IDMT-SMT-Guitar](https://zenodo.org/records/7544110), version 2, archive `IDMT-SMT-GUITAR_V2.zip` (1,329,918,978 bytes; published MD5 `06796e08731bccffaed6ae59361486e4`). Its included dataset description is more specific than the Zenodo description, which reverses datasets 1 and 2: dataset 1 is the single-note and chord collection. Dataset 1 uses two electric guitars, a Fender Stratocaster and Ibanez RG2820, plugged directly into the audio interface line input. Each single-note recording has one pluck, and covers strings 1–6 and frets 0–12. Dataset 1 is 44.1 kHz, 16-bit mono. The separate chord folders are excluded. The same official document lists two musicians for dataset 1 without identifying individual performers in the inspected XML; separating guitars does not establish player independence.

The selection is 78 Ibanez Power Strat Clean Neck HU single-note WAV/XML pairs for calibration and 78 Fender Strat Clean Neck SC pairs for held-out evaluation. Each is an independent recorded note; guitar and pickup are confounded in the split. Labels record MIDI `pitch`, absolute `onsetSec` and `offsetSec`, plus string, fret, excitation and expression. Inspected examples use `EGUI`, `PK`, `NO`. Verify every selected label before use. The [2014 paper](https://www.dafx14.fau.de/papers/dafx14_christian_kehling_automatic_tablature_trans.pdf) describes manual annotation of note parameters for its dataset, without establishing a time-error bound for each dataset 1 note. A separate [50-note reannotation study](https://domenicostefani.com/publications/2024AM-preciseonset.pdf) reports mean absolute onset discrepancy 8.5 ms, standard deviation 9.2 ms for IDMT; this is not a bound on any selected label or a validated uncertainty distribution. Freeze tolerance sensitivity reporting and avoid interpreting sub-millisecond differences as ground truth.

Metadata checks found all 156 XML files have exactly one event, `EGUI`, `PK`, and `NO`; both splits cover each of the 78 string/fret pairs and their pitches agree with standard tuning. All WAV headers are mono, 44.1 kHz, 16-bit. Three calibration offsets exceed the exact file duration by less than 33 microseconds due to decimal precision; clamp an offset to the duration when interpreting labels, while retaining original XML bytes.

Fraunhofer licenses the dataset for evaluation under [CC BY-NC-ND 4.0](https://www.idmt.fraunhofer.de/en/publications/datasets/guitar.html): noncommercial research is compatible with the stated evaluation purpose, while redistribution of adapted material has restrictions. Preserve source attribution and keep extracted files unchanged. The complete ZIP is not downloaded or MD5 verified; entry CRC checks catch corruption but do not authenticate archive identity. Source and ranges, selected original file paths, CRCs and SHA-256 hashes are recorded in `assets/stage6/data-provenance.json`.

Other sources considered:

- [IDMT-SMT-Audio-Effects](https://www.idmt.fraunhofer.de/en/publications/datasets/audio_effects.html): real electric-guitar recordings include no-effect notes and pitch metadata, but no verified onset-time labels; not suitable as the primary joint pitch/onset benchmark. Archive is 6,454,496,906 bytes, published MD5 `91e845a1b347352993ebd5ba948d5a7c`; CC BY-NC-ND 4.0.
- [EG-IPT](https://explore.openaire.eu/search/dataset?pid=10.5281%2Fzenodo.15205643): real electric-guitar isolated note performances with a DI channel, but precise note pitch/onset labels were not established. ZIP 23,757,983,313 bytes, published MD5 `48a5135adfd090515ff0af7dc5c3c32f`; CC BY 4.0 per Zenodo API. It is a technique dataset and is not a substitute for verified onset labels.
- [EGDB](https://arxiv.org/html/2202.09907): real Stratocaster DI and pitch/onset MIDI but primarily musical polyphony; annotations use score timing and per-string onset detection, with some manual correction. The separate 50-note study reported 34.6 ms mean absolute discrepancy and 31.4 ms SD. Confirm usable licensing and monophonic selection before use.
- [GOAT](https://doi.org/10.5281/zenodo.15690894): real electric DI, but the dataset record requests researchers contact its authors, so it is excluded under the no-contact constraint.
