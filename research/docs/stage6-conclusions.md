# 第六阶段结论

已用公开 IDMT 单音 DI 完成前端校准。78 条 Ibanez 校准、78 条 Fender 留出，带原始 MIDI 音高和起止 XML；先冻结协议、代码、版本与哈希，再分析真实音频。按校准选择并先行保存的设置为 **128 ms pYIN / 0.8 门槛**。

在 Fender 留出标签稳定段上，固定 0.8 时，64→128 ms 将覆盖从 **76.54% 提高到 99.85%**，接受帧音高正确均为 100%。校准组长窗正确为 99.33%，仍有一条高概率八度差，不能声称概率就是音高正确率或所有音符都正确。

主起音 64 ms 虽找全 78 次事件，却多报 66 次，**F1=0.7027，未过预设 0.80**；128 ms 对照为 0.8571，未据此事后替换主项。下一步应优先研究重复检峰，再用新的连续单音/同音重复素材确认。

保留生产基线与第五阶段失败结果；190 项回归通过。完整表格、时序诊断、选择规则、原始素材和局限见 [实验报告](stage6-findings.md)及 [协议](stage6-protocol.md)。当前仅为两把吉他、MIDI 40–76 的干声校准，湿声、力度、检索、部署仍待验证；Free Bird 继续暂停。
