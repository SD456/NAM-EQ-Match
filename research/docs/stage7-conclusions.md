# 第七阶段结论

先冻结后比较两种相邻峰合并规则，在新取得的 18 段连续单音 DI 上按乐句隔离校准和留出，并保留旧基线、128 ms 音高候选及全部第六阶段结果。

校准选择 **保留最早峰 / 80 ms**。新留出多报从 **169 降到 93**，近邻多报从 **49 降到 1**，macro F1 从 **0.5335 提高到 0.6717**；同时增加 1 个 ±50 ms 下的未匹配事件，未达 0.80。最强峰 / 80 ms 有 15 个严格未匹配事件，±100 ms 下全部恢复，说明常见风险是代表峰时间偏移，不能一概称为合掉两次物理拨弦。

选定项保留了所测 5 个快速换音对、9 个同音重拨对，但没有快速同音或 ≤80 ms 的真事件支持。门槛判决为 **insufficient_evidence，不晋升**。历史孤立音重复峰也减少，但属于已知数据回放，不能用于改选。

完整数字和归因见 [实验报告](stage7-findings.md)。下一步优先补短间隔真实重拨并研究代表峰选择、非近邻误报；[补录单](stage7-recording-spec.md)提供六条独立 DI 的演奏与标注规范。232 项回归通过，旧原件和结果摘要一致，Free Bird 继续暂停。
