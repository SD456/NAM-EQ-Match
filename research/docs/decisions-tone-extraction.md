## 当前有效目标

输入一段参考 WAV 中的吉他湿声，利用深度学习得到代表其整体音色处理的数字模型。该模型随后处理新的吉他干声，输出具有目标整体音色和响应的湿声，同时保留新演奏的音符、节奏、颤音和力度变化。

用户最新明确：现阶段不必拆分全套设备，不要求识别品牌型号、设备顺序或每个效果器的旋钮参数。最终交付由“原始设置识别报告”改为“整体数字模型”。不能用设备识别报告替代可用模型，也不能用参考录音的重放或仅去除效果替代前向效果建模。

## 当前交付与工程方向

- 核心产物是能够处理新吉他干声的整体数字模型，并附运行方式、适用输入条件与质量验证结果。
- 可试听的新演奏输出用于检验模型是否可用；设备名称、链顺序及物理旋钮不再是首阶段必交内容。
- 优先验证与现有 NAM_LV2 兼容的 `.nam` 产物，这是依据现有系统提出的工程方向，尚不是用户明确限定的唯一文件格式。其他网络格式若作为研究中间产物，须注明其加载方式与迁移缺口，不能改扩展名冒充 `.nam`。
- 整体处理若已包含箱体或麦克风染色，验证播放路径需避免无意叠加同类处理。模型究竟涵盖了什么，以实验与输入条件说明为准。

## 当前验收方向

此前“先用已知软件／数字模型进行客观验证”的决定继续适用，但验收对象改为前向处理能力，不再按设备名称或旋钮还原准确率验收。

1. 用已知效果系统处理参考干声，生成目标湿声；盲建模过程只获得该目标湿声及允许的先验，参考真实干声与原设置不泄漏给它。
2. 用建模阶段完全未使用的新 DI，同时经过学得模型和原效果系统，比较输出音色、动态响应、内容保持与伪影。
3. 若另设真实配对监督训练组，明确标为能力对照，不能把它的成绩算作仅湿声建模结果。
4. 检验不同音符、力度、延音和演奏内容下的表现，避免只在参考片段上拟合良好。伪干声重建质量和训练损失仅作中间诊断。
5. 现有真实 WAV 缺少原处理系统和对应 DI 真值，用于音色与可用性探索，不能据此证明恢复了唯一真实处理函数。
6. 记录失败案例、素材限制、模型格式与运行资源。适用范围、数值质量门槛和实时性能尚待实验设计确定。

## 仍需验证的假设与工作默认

- 参考吉他与拾音器本身的音色和效果处理存在混杂；能否分离、在另一把吉他上能保持多少目标特征，是研究问题，不预先宣称只恢复了原设备。
- 先按效果设置基本固定的时间区间研究，允许人工选段；自动检测设置切换暂不增加为首阶段要求。这是工作默认，未作为用户逐项确认的决定。
- 拟合参考湿声并不等于能正确处理新的真实 DI；整体模型的有效性以新输入上的结果判断。
- 后续技术设计需要选择去效果或无配对建模路线、模型结构、数据、指标和格式验证方法。当前更新需求，不在本轮指定算法或启动训练。

### 当时使用的目标区分

- 原始设置识别：判断实际使用了什么、如何连接、参数是多少。
- 等效配置：可能采用不同设备或参数，但产生接近的声音。
- 黑盒模型：学习输入到输出的变换，不一定提供可读的设备和旋钮。

该历史阶段曾以第一项为最终目标，首阶段只交付识别报告；此交付选择已经被最新的整体数字模型目标替代。

### 当时的首阶段需求草案

#### 输入与目标

输入参考吉他湿声 WAV，以及可选的器材或录音方式提示；不要求提供同次演奏的真实干声。识别参考中实际施加的失真、音箱和箱体处理，输出有依据的设备候选、连接顺序和参数范围。允许未知与拒识，不能把等效音色配置当作原始设置。

最终目标面向开放来源；首轮客观结论只覆盖明确列出的软件、数字模型、链结构和参数范围。具体测试库不代表开放世界已被覆盖。

#### 识别报告

| 内容 | 报告要求 |
| --- | --- |
| 分析对象 | 标明文件及实际分析的时间区间，以便复核。 |
| 设备 | 按失真、音箱、箱体给出有依据的候选；支持到具体软件或数字模型身份时明确标识，不足时标明未知。 |
| 顺序 | 给出有依据的连接关系；无法区分的局部顺序保留不确定，不强制拼出唯一完整链。 |
| 参数 | 与具体候选关联，保留该实现的旋钮名称与单位，给出估计范围或无法确定。数字模型没有可查证原旋钮时，不从音色名称推断硬件旋钮。 |
| 依据 | 区分音频支持、用户提供和两者共同支持；提示不是音频已经识别成功的证据。 |
| 局限 | 记录未知设备、待识别处理、干扰及拒识原因；未识别因素仍可能降低其他判断的可信度。 |

#### 客观验收

- 使用实际身份、顺序和设置可查证的软件或数字模型录音。评测真值与识别输入分开，设置不能泄漏到识别过程。
- 分别评价设备候选、链顺序和参数范围。记录候选数量、参数区间宽度和真值覆盖情况，避免靠罗列所有候选或给出全范围获得虚假的好成绩。
- 同时记录回答覆盖情况、错误回答和拒识，避免靠全部拒识获得虚假的可靠性。
- 使用不同演奏内容和力度条件检查识别稳定性；同一设置不应仅因音符、颤音或拨弦变化就被误认为另一套设置。不同吉他与拾音器作为需要记录的影响条件。
- 带提示与不带提示的结果分别记录。首轮结论注明样本、版本、设置、测试条件、失败案例及覆盖范围。
- 现有三首参考只用于未知真值探索，不能据其听感匹配程度计算原设置识别准确率。

### 当时待核对的工作默认

以下为收敛首阶段范围的建议默认，不标为用户已逐项确认的决定：

- 按固定效果设置的片段识别，允许人工选择时间区间；自动检测效果切换暂不列为要求，不要求用户预先裁剪原文件。
- 不复制参考演奏者的具体力度轨迹；将效果处理对不同输入力度的响应视为处理规律的一部分。
- 按证据支持程度逐层细化设备与参数；数值置信度需经过校准才使用，不先给未经验证的百分比。
- 首轮交付完整的研究与识别报告，先测基线能力，不预先承诺识别准确率或产品可用程度。
