# 第二阶段已知音色检索实验协议

2026-11-15，真实素材检索前冻结。评价对象是当前 NAM＋箱体链与输入增益检索器，以及检索后拟合的一条受限 EQ。第一阶段的 76 项检查验证工程行为。本实验另问一个问题：只给一段目标湿声和另一段干吉他演奏，检索器选出的设置在第三段 DI 上能否接近目标系统？

## 试验单位与素材

- 10 个真实原生 48 kHz NAM，来自 5 个模型家族。元数据均标 overdrive，未经确认的 clean/crunch/lead 听感类别不作分层。两条 CC0 实录箱体 IR 与 amp-only NAM 配对，完整音色 NAM 沿用模型内箱体。每个 NAM 各取一条基础链，另加两条同一 NAM 换箱体的候选，共 12 条完整链。清单记录来源、许可、SHA-256、家族归属和链类型。[NAM 与箱体素材](../assets/stage2/models-ir-provenance.json)
- 冻结配置列出四个目标 NAM：`AMP-2204-1`、`AMP-Sbgo-1`、`G12-2204-3` 和 `V30-SLO1-3`。前两者各配主箱体 `bg412s-godmode-dv77-v30-mix` 作为目标，在候选库另接 `ir-brown-cab-audix-i5` 作同底 NAM 换箱体的对照。后两者使用完整链。实际来源与哈希以运行清单为准。[机器配置](../experiments/stage2.json)
- A、B、C 取 Guitar-TECHS P3 的同一条 `directinput_01.wav` 录音，范围依次为 [0, 8)、[8, 16)、[16, 24) 秒。双声道采样值完全相同，取左声道。记录原始 RMS/peak，源硬件输入增益未知。三段用于检验同一次录音中乐句的变化，不算三个独立演奏者或三个录音 session。C 留到排名及校正参数确定后再评价。[DI 录音与切段清单](../assets/stage2/di-provenance.json)
- 只用 A 的 8 秒原片求一次校准量，k = −18 − 20 log₁₀(RMS(A)) dB。目标和候选都在原始 DI 上施加 k + g 后送入 NAM，B、C 沿用同一 k。比较数字检索增益时均以这个共同参考系为准。单一公共增益保留了各段力度差；若不同源的模拟增益未知，这部分差异仍在跨 DI 结果中。

## 2 × 2 对照

每条目标链各造 0 和 +6 dB 两个真设置。令目标演奏 T 分别为 A、B，另一段为 U。先以真设置在 T 上产生湿声，再构造如下四格。目标后级 E1 为固定的宽带 +3 dB 高频搁架，转折约 1.2 kHz；参数、实际实现和频响随运行保存。候选检索时都不预装 E1。

| 目标版本 | 候选用 T 演奏 | 候选用 U 演奏 |
| --- | --- | --- |
| E0 原始链 | 同 DI，无额外 EQ。检查真链、真增益、打分和入围流程能否闭合。 | 跨 DI，无额外 EQ。对比左格可见切换演奏带来的变化。 |
| E1 原始链加固定搁架 | 同 DI，目标加 EQ。对比上格可见单独加入频响变化的影响。 | 跨 DI，目标加 EQ。与本行左格及本列上格分别比较。 |

4 条目标链 × 2 个真增益 × 2 个目标演奏，每格 16 例，共 64 例。四格共享目标链、增益和录音，比较时按这三项配对。在每个目标方向固定目标湿声后换候选 DI，避免把 A→B 与 B→A 的差异当作同一反事实。同 DI 给检索器提供了部署时通常得不到的对应演奏，仅作对照。16 例并非 16 个独立设备或演奏者。

## 基线与搜索

冻结当前 `vendor/NAM-EQ-Match/tonematch/features.py` 的特征和权重。总分越小越好，等于 `nonlinear_distance["total"] + 0.25 * eq_penalty`。这一项 EQ 惩罚为 80–8000 Hz 对数频点的平均绝对 LTAS 差除以 18，只在排名中使用。排名完成后才用搜索演奏的渲染与目标湿声拟合校正 IR。不得在 C 上挑模型、增益、校正曲线或消融版本。

1. 对每条候选和每种 A/B 输入预计算 −12…+12 dB、步长 1 dB 的指纹。粗排在 −12、−6、0、+6、+12 dB 中为每条链选其最低分，留前五条。精排在入围链的粗排最佳增益 ±3 dB 内按 1 dB 扫描，裁至边界后重新排名。并列按事先固定的候选和增益顺序处理，记录可见的并列或极小分差。
2. 两阶段使用同一个 8 秒 DI 区间，并保存目标真链的粗排和精排名次。此时生产搜索的 8 秒粗段和最多 16 秒精段使用相同输入。另将所有候选在完整 25 档网格上排序，与两阶段结果比较。全扫仍排错说明该评分本身能偏爱错链；全扫找回而粗排未入围提示剪枝损失；全扫找回但粗排入围、精排未找回时比较真链所搜的增益区间。
3. 逐例记录真链真增益、真链搜索最佳档和获胜者的分数、分项以及前两名分差。总分是带方向且未经置信度校准的距离，A→B 和 B→A 不取倒数。测试中不得根据真值重排候选或重调权重。

## 判据与计数

| 项目 | 预设口径 |
| --- | --- |
| 链身份 | 正确指 NAM 哈希和箱体 IR 哈希均相同，full-rig 的外置 IR 为空。另报 NAM-only 以及有明确出处的家族命中。近似音色不折算成 exact Top1。完全重复的链须在试验前按哈希识别。 |
| 同 DI／E0 工程对照 | Exact Top1 16/16。另列 0 和 +6 dB 的真档恢复情况，以 1 dB（一步）为数值误差参照。当完全等效的候选或数值并列影响身份或档位时，保留 exact 指标并注明原因。 |
| 两个跨 DI 格的内部检查 | E0 和 E1 各自要求精排 exact Top1 ≥12/16，exact Recall@3 ≥14/16，coarse Recall@5 = 16/16。Recall 的真值每例只有一条。漏进粗排五强在精排 Top1/Top3 中记失败，分母不变。同 DI／E1 也逐项报告。 |
| 增益 | 本次全部记 nominal 数字增益偏差。选对完整链时单列估计档与真档的绝对差和分母；每一例另统计强制固定真链时的档位误差，避免只看成功检索的例子。不同 NAM 的同名增益档可有不同非线性响应，单个 NAM 的近线性或深饱和区也可能对多档输入增益给出近似音色。本次不推断物理增益可辨识性。 |
| 第三段的功能接近 | C 上单例同时满足电平对齐后的配对 MRSTFT 谱收敛度 ≤0.20 和 80–8000 Hz 居中 LTAS MAE ≤1.5 dB，计一次客观筛选命中。报告命中例数、分母及两项连续值。门槛服务于本次内部筛选，不能换算成主观听感保证。 |

12 条不同链均匀随机排序时，单个真值的 Top1、Recall@3 和 coarse Recall@5 参照依次为 1/12、3/12 和 5/12。描述性结果逐格列分子、分母，并按 T=A/B、目标链、真增益看失败是否集中。内部阈值用于决定是否继续检验当前方案，不外推产品准确率，也不因某格未过而放宽。

## 第三段的配对声音评估

将没参与排名或 EQ 拟合的同一个 C，分别输入目标真链和已经选定的链。目标侧复用相同真增益和 E0/E1；候选侧复用检索增益。校正 FIR 使用既有 2048 taps、半倍频程平滑、±4.5 dB 上限，拟合所见输入只能来自该例的搜索和目标演奏。记录实际频响峰值与校正前后 C 的误差，另列已知真链真增益的参照。若同样给真链拟合了受限 EQ，须区分已知的目标 E1 和从湿声估出来的 FIR。

跨演奏时音符和起音不对应，以聚合指纹和检索名次比较。逐帧 MRSTFT 只用于同一输入的成对渲染。谱收敛度在每个 FFT 尺度为两段幅度谱差的 Frobenius 范数除以目标幅度谱范数，再跨尺度平均。C 的客观音色评价只允许单个整段标量校平输出电平，记录窗长、hop、尾长处理与校平方式；若电平在 C 上估计，它只属于评价指标，不写回预设。LTAS 仅用频带内相对频响误差。比较输出电平和残响尾时需保留原始电平和长度。被选中的不同链若在 C 上过线，只能说在这一条留出演奏及这两个尺度指标上接近。

## 失败如何解释

| 原评分项 | 输入或 EQ 造成的具体混杂 |
| --- | --- |
| 400 ms crest、kurtosis、peak density | 改拨弦力度、音间停顿或叠音会改变峰值、波形分布、超过半峰值的样本比例。宽带 EQ 也会改变瞬态峰值。 |
| dyn_range、sustain_ratio | 受活动门限、句中轻重音和停顿影响。`sustain_ratio` 比较活动 RMS 窗的中位数与最响十分位的平均值，未追踪任何单个音符的衰减常数。 |
| hf_ratio、spec_crest_hf、drive_gap | 拨弦位置、音区和箱体/EQ 可同时改变高频比例与峰均比。drive_gap 又使用 crest、kurtosis、峰值密度和 hf_ratio，欠驱动惩罚系数 1.5、高于过驱动 0.7；这些证据会在多个项中叠加。 |
| flux、MFCC 标准差与一阶差分标准差 | 相邻活动帧已按原时间轴处理。音阶、和弦密度、起音与颤音依旧会改变谱流和系数分布；丢弃 c0 无法让这些特征对箱体或搁架完全不变。向量距离按目标范数归一化，也会随目标方向改变。 |
| LTAS 惩罚和拟合 EQ | 异曲的音符占比、拾音器或琴弦差异可被误当作设备残余频响。比较校正前后 C，才能检验训练段拟合的修正在新输入上是改善还是恶化。 |
| 箱体卷积尾长 | 主／次箱体分别为 61,235／24,000 taps，生产链卷积保留全尾，full-rig 则无外置箱体尾。附加的低能量尾段会改变活动帧比例、百分位和 LTAS 统计量。排名可能同时利用这一渲染长度差，不能把同底 NAM 的箱体命中全部归因于可听频响。 |

预声明的诊断排序为去掉 drive_gap、移除显式高频谱特征组、移除动态／纹理组、去掉 EQ 惩罚、只用 EQ 惩罚。应记录每组实际移除项；例如保留 drive_gap 时其中仍含高频信息。每种消融对候选和增益重新排序。消融之间只作解释性对比，不挑其中表现最好的替代已冻结基线。若在同底 NAM 两个箱体间错选，分别看完整链身份、NAM 身份和 C 的配对误差；仅凭同家族或相近 NLD 无法判定功能等价。

旧 MockAmp／合成 DI 的反事实记录独立于真实 NAM 实验。真实素材的规模、来源和覆盖范围决定可解释边界。本试验没有开放库未知目标，也未覆盖歌曲分离、不同硬件电平、全部吉他或插件／板端回放。Free Bird 不在本协议的评测素材中。
